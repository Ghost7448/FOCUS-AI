# FOCUS AI — MySQL Edition

مشروع FOCUS AI مبني باستخدام Next.js 14 وTypeScript وTailwind CSS. تم إزالة Supabase بالكامل، وأصبح تخزين البيانات والمصادقة من خلال MySQL وواجهات API داخل Next.js.

## المتطلبات
- Node.js 20 أو أحدث.
- MySQL 8.0 أو أحدث.
- إعداد SMTP لإرسال رسائل التحقق واستعادة كلمة المرور عند تفعيل التحقق بالبريد.

## الإعداد لأول مرة
1. أنشئ قاعدة بيانات MySQL فارغة باسم `focus_ai`.
2. شغّل الملف `database/schema.sql` على قاعدة البيانات.
3. انسخ `.env.example` إلى `.env.local`.
4. ضع بيانات اتصال MySQL في `DATABASE_URL` أو متغيرات `DB_HOST / DB_PORT / DB_USER / DB_PASSWORD / DB_NAME`.
5. اضبط `APP_URL` على رابط الموقع، وأدخل إعدادات SMTP.
6. نفّذ `npm install` ثم `npm run dev`.
7. افتح `http://localhost:3000`.

## المصادقة والأمان
- كلمات المرور تُخزّن باستخدام bcrypt مع cost factor 12.
- الجلسات تستخدم رموزًا عشوائية، ويُخزّن Hash الرمز فقط في قاعدة البيانات.
- Cookie الجلسة HttpOnly وSameSite=Lax وSecure في الإنتاج.
- التسجيل العام يسمح بدور Student أو Teacher فقط.
- حساب Admin يتم إنشاؤه من سكربت موثوق، وليس من صفحة التسجيل.
- رموز التحقق وإعادة تعيين كلمة المرور مخزّنة كـHash ومحددة الصلاحية.
- محاولات تسجيل الدخول محدودة لكل بريد وعنوان IP.
- يجب فحص ملكية البيانات والصلاحيات داخل كل API/Server Action قبل إضافة أي ميزة جديدة.

## إنشاء أول Admin
اضبط `ADMIN_EMAIL` و`ADMIN_PASSWORD` و`ADMIN_NAME` في بيئة الطرفية ثم نفّذ:
```bash
npm run db:admin
```
يجب أن تكون كلمة المرور 12 حرفًا على الأقل. لا تضع بيانات حقيقية في ملف .env مرفوع للمستودع.

## استعادة كلمة المرور
صفحة `/forgot-password` ترسل رابط استعادة صالحًا لمدة 30 دقيقة. تغيير كلمة المرور يبطل الجلسات القديمة.

## الحالة الحالية
هذه مرحلة تأسيسية لتحويل قاعدة البيانات والمصادقة إلى MySQL. أدوات الطالب والمدرس والإدارة الظاهرة في لوحة التحكم ما زالت قيد التطوير وليست وظائف مكتملة.
